# Data Engineering for Robot Learning

Robot learning resources are largely written for academic researchers, with relatively little material designed for people coming from data engineering backgrounds.

This repository documents my journey into robot learning and organizes what I learn into small, structured modules. Each module focuses on a specific concept, tool, or practical problem, with particular attention to the data systems that support robot learning.

The goal is to create a clear learning path for data engineers and other practitioners who want to explore the field without approaching it from a purely academic perspective.

This is not intended to be a comprehensive robot learning course. It is a structured record of my learning, refined into material that may help others entering the field.
