Data Engineering for Robot Learning

Robot learning resources are largely written for academic researchers, with relatively little material designed for people coming from data engineering backgrounds.

This repository documents my learning journey through robot learning and organizes it into small, structured modules. Each module will focus on a specific concept, tool, or practical problem, with an emphasis on the data systems that support robot learning.

The goal is to create a clear learning path for data engineers and other practitioners who want to understand the field without starting from a purely academic perspective.

This is not intended to be a complete robot learning course. It is a structured record of what I learn, refined into material that may help others entering the field.
